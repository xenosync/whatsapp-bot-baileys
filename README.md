# WhatsApp Bot Baileys

Open-source WhatsApp bot built with Baileys/Node.js featuring AI chat handler, media downloader, group automation, and frame extraction.

## Features
- AI chat handler (OpenAI/MiMo integration)
- Multi-platform media downloader (TikTok, Instagram, YouTube)
- Group management & tag scheduler
- Video frame extraction with HD enhancement

## Stack
- Node.js + Baileys
- FFmpeg
- REST API integrations

## Usage
```bash
npm install
node index.js
